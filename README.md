# 🚀 太空舱宣传视频生成 Agent

> 面向电商宣传的太空舱产品视频自动化生成工具：**10 秒一镜到底看房 walkthrough**——外景定帧 → 进门 → 客厅 → 主卧 → 卫生间 → 回主卧落地窗看景，像真人连贯走完整个太空舱；外景在 **雪地 / 深林 / 草地** 中随机呈现。一键生成、批量产出、可下载。

基于 **Streamlit** + **阿里云 DashScope**（多参考图生视频 r2v）构建。参考图由用户预置于 `assets/references/`，生成时**不生成任何参考图/首帧图**，直接按动线顺序垫图出视频。

```

                       ▼
┌─────────────────────────────────────────────────────────┐
│           线性 Pipeline（单条视频编排）                   │

│  场景编排 → 参考图按动线排序 → 多参考图生视频 → 归档      │

                   │  视频生成模型         │

                   └──────────────────────┘
```

### 单条视频流程

1. **场景编排**：从 雪地 / 深林 / 草地 **随机抽取**（不与上一条连续重复）。
2. **参考图收集**：按参观顺序排序——外饰 → 客厅 → 主卧 → 卫生间 → 主卧（末尾重复主卧，锚定「回主卧落地窗收尾」）。r2v 模型按 media 顺序参观房间，**顺序即动线**。
3. **视频生成**：参考图 + 动线提示词 → `wan3.0-video` 多参考图生视频（异步提交 → 轮询 → 下载 MP4）。
4. **归档**：记录场景/动线/提示词/参考图/视频路径到 `index.json`。

### 一镜到底动线（默认 10s，节拍随时长等比缩放）

| 时间 | 画面 |
|------|------|
| 0 – 1.5s | 外景定帧（**全片唯一一次外饰**），舱门已开、暖光外溢 |
| 1.5 – 2.5s | 穿过敞开的舱门 |
| 2.5 – 4s | 客厅（沙发 / 舷窗 / 壁挂电视 / 暖光灯带） |
| 4 – 5.5s | 主卧（大床 / 衣柜 / 床头灯） |
| 5.5 – 7s | 穿过拱门进卫生间（壁挂洗手池 / 背光镜 / 弧形玻璃淋浴） |
| 7 – 8.5s | 回主卧，走向落地窗 |
| 8.5 – 10s | 缓慢推镜看景，定帧收尾（窗外只有自然景观） |

## 🚀 本地运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入 `DASHSCOPE_API_KEY`（本项目已内置 `.env`）。

### 3. 启动

双击 `一键启动.bat`，或：

```bash
streamlit run app/main.py
```

浏览器打开 `http://localhost:8501`。

## 🖼️ 参考图使用

参考图由用户预先放入 `assets/references/`，生成时**直接垫图，不生成任何参考图**。

- 外饰：文件名含 `exterior` / `外饰`（如 `exterior_1.png`），取第 1 张作开场外景。
- 内饰：文件名含 `interior` / `内饰`，再按房间关键词匹配——`living` / `客厅`、`bedroom` / `主卧`、`bath` / `卫生间`。
- **参考图顺序即参观动线**：外饰 → 客厅 → 主卧 → 卫生间 → 主卧（末尾重复主卧锚定收尾）。
- 某房间缺参考图时该站不垫图，仅靠提示词文字描述。
- 也可在界面「参考图管理」中直接上传；系统按文件名自动区分外饰与内饰。

## ⚙️ 配置说明

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `DASHSCOPE_API_KEY` | 阿里云 DashScope 密钥 | 必填 |
| `VIDEO_MODEL` | 视频模型 | `wan3.0-video` |
| `VIDEO_RESOLUTION` | 视频分辨率 | `720P` |
| `VIDEO_RATIO` | 视频比例 | `16:9` |
| `VIDEO_DURATION` | 视频时长（秒），动线节拍随之等比缩放 | `10` |
| `DAILY_VIDEO_COUNT` | 每次生成条数 | `5` |
| `REFERENCES_DIR` | 参考图目录 | `./assets/references` |
| `OUTPUT_DIR` | 输出目录 | `./data/output` |

> `IMAGE_MODEL` / `USE_REFERENCE_IMAGE` 已不再使用：参考图由用户预置，管线不生成任何图像。

### 视频模型选择

| 模型 | 类型 | 说明 |
|------|------|------|
| `wan3.0-video` | r2v 多参考图生视频 | 默认，按 media 顺序参观房间 |
| `happyhorse-1.1-r2v` | r2v 多参考图生视频 | 多参考图协议，与 wan3.0 同分支 |
| 其他 wan 系列单图模型 | 图生视频 | 只取第 1 张参考图作首帧 |
| `kenburns` | 运镜拼接 | 零视频成本兜底（需 moviepy/ffmpeg） |
